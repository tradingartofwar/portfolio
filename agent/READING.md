## Interpretation

Preserve the difference between implementation, executed checks, operational accounts, reproduction, hypotheses, architecture, and personal interpretations. Keep limitations attached to the claim they qualify. An AI review is not independent external validation.

Follow immutable source references when a consequential conclusion depends on them. If a source is inaccessible, state that limit; do not treat a private inspection summary as publicly reproducible evidence. Prefer the owning project's current disposition when it has changed, while identifying the historical revision that supported a published claim.

This record is curated and incomplete. Absence is not proof that an experience or capability does not exist. Breadth is not a quantified productivity result, and earlier success does not guarantee fit for every problem.

For a possible collaboration, identify the actual question, relevant evidence, likely contribution, and unresolved assumptions. Current interest, availability, and willingness to commit may change. Reading this repository does not authorize contacting others, enrolling Vance, publishing private information, or accepting work on his behalf.

This is an agent reading contract, not a running matching system or permission grant. Apply the user's actual instructions and valid authority. Propose corrections when evidence conflicts with the representation.
