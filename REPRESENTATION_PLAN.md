# Vance Human–AI — representation plan

**October 15, 2026 · Current direction**

## Purpose

Build a correctable, source-grounded representation of a Human–AI partnership that agents can navigate at increasing depth. It should help identify worthwhile collaboration, including employment, while keeping the person's interests and choices central.

A concise overview points to research, systems, contribution accounts, and evidence. Deeper paths preserve distinctions needed for a particular decision. The goal is useful selective access, not an expectation that a human or an agent reads everything.

This repository began as a portfolio. The [October 14 editorial plan](history/PORTFOLIO_PLAN_2026-10-14.md) remains part of its history. Existing cases, claim IDs, verification records, and source links remain useful.

## Information architecture

| Surface | Responsibility |
| --- | --- |
| README.md | Brief orientation, current purpose, and paths into evidence |
| agent/READING.md | How agents navigate, qualify conclusions, and respect authority |
| about/ | Human–AI responsibilities, contribution attribution, and review limits |
| research/ | Research questions and bounded findings |
| case-studies/ | What was built, tested, corrected, stopped, or proposed |
| evidence/ | Stable claim register, evidence standards, and verification records |
| templates/ | Consistent requirements for new public cases |
| history/ | Earlier plans, clearly marked as historical |

Original research and operational repositories retain source authority. This record publishes approved explanations and its own verification work. It is not a warehouse for private source material or a complete personal history.

## Near-term focus

1. Establish the agent reading path using existing evidence. This edition supplies that guide and updates the repository's purpose.
2. Add current interests and desired contributions in a small, owner-approved form when a concrete collaboration needs them. Distinguish interests, past work, current commitments, and available attention.
3. Extend routes into evidence where an actual decision exposes a gap. A structured index may help later; it is not yet implemented or required before a first useful connection.
4. Generate concise human-facing views for a specific audience: a research team, employer, potential collaborator, or introductory video. Keep claims traceable to the same evidence register.

Avoid manufacturing completeness. New operational cases require appropriate public evidence and sanitization. Credentials and employment chronology still require exact verification before detailed publication. Public exposure does not make private context appropriate to amplify.

## Relationship to the wider vision

The proposed Human–AI Network would help people find others with related interests and complementary contributions, then work together on questions they choose. This repository would represent one partnership within that network.

The network's architecture and implementation belong to their own project. No discovery service, plugin, automatic collaboration provisioning, or measured reduction in human cognitive load is established by this public record.

The working prediction is that dependable AI and external structure can recede from everyday attention while preserving inspection and correction. The intended human benefit is more time and freedom for what matters. That prediction motivates development; it remains distinct from demonstrated outcomes.
